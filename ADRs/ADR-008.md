# ADR-005 — Notificações Push + Expo server 

## Status
- Aceito
---
## Data
04/09/2025
---

## Contexto

Decisão de qual serviço vamos utilizar para enviar notificação push mobile. 

---

## Decisão

Foi escolhido o Expo push service pois como web é utilizada expo router e o app mobile (repositorio a parte) também é um setup expo, para evitar integrações mais complexas, foi decidido o expo push service


---

## Alternativas Consideradas

### Alternativa 1

Instalar o expo push service como server de notificações mobile (Android/ios)
 
---

## Consequências
Novo adapter e nova table no banco para salvar o token dos dispositivos. 

### Positivas

- facil integração com o expo no front e mobile. 
- uma unica integração para ambas plataformas mobile. 

### Negativas

---
### Alternativa 2

OneSignal como server de notificação
 
---

## Consequências

integrar esse novo serviço para todos os ambientes, e salvar token no banco 

### Positivas

- escalável
- possui um bom dashboard de controle e um bom analitycs

### Negativas

- necessário um setup para cada plataforma mobile
- integração de terceiro e um pouco mais complexa.
