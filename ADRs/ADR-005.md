# ADR-005 — Refactor frontend

## Status
- Aceito
---
## Data
04/08/2025
---

## Contexto

Refatoração do frontend devido ao novo design e padrão de cores e fontes.Aproveitando para sair do tamagui para utilizar o nativewind e utilizar tags mais puras  

Quais limitações existem?


Quais requisitos influenciam?


---

## Decisão

A refatoração do frontend está sendo feita pois o nativewind é um pouco mais claro na forma de codar, além de que foi alterado todo a questão de layout, padrão de cores e fontes. 

A ideia ainda mantem o expo router + react native, porém muda todo o restante em questão de arquitetura e padrão de UI 

---

## Alternativas Consideradas

### Alternativa 1

Descrição 
Frontend com React Native + Expo router + native wind (tailwind para react native)

### Positivas

- Desing Melhorado
- Melhor performance

### Negativas

- Retrabalho
- Sistema de notificações que é importante pode ser prejudicado por conta do SDK do expo go.
