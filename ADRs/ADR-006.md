# ADR-005 — Notificações Web 

## Status
- Aceito
---
## Data
12/08/2025
---

## Contexto

Foi adicionado um motor para envio de notificações e por enquanto ele vai respeitar só duas coisas. ele pode enviar IN APP notifications e Web Push notifications

Quais limitações existem?
Não possuimos o SDK necessário ainda no expo ios para testar o aplicativo mobile.

---

## Decisão

Foi escolhido para essa versão do MVP fazer o motor de notificações mais limitado, para que conseguissemos prosseguir com mais agilidade para liberar o MVP


---

## Alternativas Consideradas

### Alternativa 1

Descrição 
Notificação mobile, porém regredindo o SDK do projeto podendo gerar alguns bugs, 
 
---

## Consequências

### Positivas

- Desing Melhorado
- Notificação ideal para o sistema

### Negativas

- Retrabalho
- Sistema inteiro pode parar de funcionar por conta do SDK 

---
### Alternativa 2

Descrição 
Notificação Push, mantem o sistema web porém não temos um aplicativo e sim um sistema web. 
 
---

## Consequências

### Positivas

- Notificação é enviada e motor ja está criado

### Negativas

- A Notificação só é vista quando o sistema está aberto no navegador. 

---

## Impacto Arquitetural

Domínios afetados

 - Todos do frontend 

Engines afetadas

 - Notifications
